# Service Interfaces: Certificate Service

## CertificateRepositoryInterface

```python
@runtime_checkable
class CertificateRepositoryInterface(Protocol):
    def create(self, dto: GenerateCertificateInput) -> Certificate: ...
    def get_by_cert_id(self, cert_id: str) -> Certificate | None: ...
    def get_by_unique_key(self, student_name: str, course_track: str, issue_date: date) -> Certificate | None: ...
    def list_paginated(self, page: int, page_size: int, search: str | None, track: str | None, include_revoked: bool) -> tuple[list[Certificate], int]: ...
    def update(self, cert_id: str, **kwargs: Any) -> Certificate | None: ...
```

## CertificateServiceInterface

```python
@runtime_checkable
class CertificateServiceInterface(Protocol):
    def generate(self, dto: GenerateCertificateInput, actor: User | None = None) -> CertificateReadDTO: ...
    def verify(self, cert_id: str) -> CertificateReadDTO | None: ...
    def get_by_id(self, cert_id: str) -> CertificateReadDTO | None: ...
    def list_certificates(self, page: int = 1, page_size: int = 20, search: str | None = None, track: str | None = None, include_revoked: bool = False) -> CertificateListResponseDTO: ...
    def download_pdf(self, cert_id: str) -> bytes: ...
    def download_html(self, cert_id: str) -> str: ...
    def export_csv(self, track: str | None = None, search: str | None = None, include_revoked: bool = False) -> bytes: ...
    def revoke(self, cert_id: str, reason: str, actor: User | None = None) -> CertificateReadDTO: ...
```

## UnitOfWork

```python
class CertificatesUnitOfWork:
    def __init__(self, session: Session):
        self._session = session
        self.certificates = CertificateRepository(session)
        self.audit_log = CertificateAuditLogRepository(session)
    
    def commit(self) -> None: ...
    def flush(self) -> None: ...
    def rollback(self) -> None: ...
```
